# Switchback

A trail finder in the spirit of AllTrails, built only on open data:
OpenStreetMap trails (Overpass), Open-Meteo elevation, weather and place search, and OSRM drive times.
Everything is in `index.html`; saved trails stay in your browser.

Trail data © OpenStreetMap contributors (ODbL). Map tiles © OpenTopoMap, Esri. Leaflet (BSD-2-Clause) is bundled inline.
